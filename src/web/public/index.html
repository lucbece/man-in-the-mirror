To invite the bot: Developer Portal → Installation → enable the bot and applications.commands scopes plus Connect and Speak, then open the URL it generates. Add Move Members and Mute Members if you want it to manage the call. No privileged intents are needed.

Keys

One home for each secret. Fields render empty because the values are never sent to this page — so leaving one blank keeps what's stored, and only typing replaces it.

Saved to data/config.json with owner-only permissions on macOS and Linux; on Windows it inherits the folder's. A .env file works too, and anything saved here wins over it. To clear a key rather than replace it, edit that file.

What it remembers

While off, the bot sits self-deafened — which is both the mechanism that stops Discord sending it audio and a badge Discord shows next to it in the member list, so everyone can see its state without taking your word for it. Required for it to notice its name, and the difference between answering in seconds and answering in half a minute. It does mean paying to transcribe everything said in the channel, not just what's buffered when someone asks.

Thinking

Without it, it can only reason over what it heard in the channel, and will say so rather than guess. Adds a few seconds to the answers that use it, because it actually goes and looks.

What the agent can reach

In agent mode it also gets tools for the call itself — moving people between channels, muting, disconnecting, leaving, and setting reminders it speaks out loud later. Each of those checks the permissions of whoever asked, not the bot's.

Speaking

Replies are spoken sentence by sentence as the model writes them, so the voice starts before the answer is finished.

Speech reaches Discord as Opus and plays untouched, which is the fastest path and avoids re-encoding every reply. The trade is that this app can't change its own loudness — right-click the bot in Discord's member list and use the user volume slider, which is per-listener anyway.

Connection

The bot needs its own account on Discord, and a token that proves it's yours. Two minutes, one page:

  1. Open the Discord Developer Portal and click New Application. The name you give it is the name people see in the member list.
  2. Open the Bot tab → Reset Token → Copy. Discord shows the token once and never again; if you lose it, just reset for a new one.
  3. Paste it below and hit Save & apply.
  4. Back in the portal, open Installation and enable the bot and applications.commands scopes plus the Connect and Speak permissions. Open the link it generates to invite the bot to your server.

No privileged intents needed — leave those toggles alone. The token is saved to data/config.json, readable only by you on macOS/Linux; on Windows it inherits the folder's permissions. You can set DISCORD_TOKEN / DISCORD_GUILD_ID in a .env file instead, but anything saved here wins.
